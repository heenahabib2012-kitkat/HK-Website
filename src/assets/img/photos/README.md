# Photography slots

Drop a photograph named after its slot (`.jpg`, `.webp`, `.png` or `.avif`) into this folder and run `npm run build`.
It automatically replaces the architectural art plate used in that slot. Recommended: 2400px on the long side, WebP/JPEG ~200–400 KB.

| Slot | Where it appears |
|---|---|
| `founder` | Founder portrait (home + About). **Use the real photograph of Habib Koya Marapatta — no AI retouching of the face.** Portrait 4:5. |
| `hero-poster` | Static fallback behind the home film |
| `home-prologue` | Home — About HK image |
| `about-hero` | About page header |
| `svc-franchise`, `svc-setup`, `svc-ops`, `svc-brand`, `svc-startup` | The five services |
| `ind-fnb`, `ind-trading`, `ind-realestate`, `ind-retail`, `ind-luxury`, `ind-professional`, `ind-technology`, `ind-investment`, `ind-healthcare` | The nine industries |
| `tl-2015`, `tl-2017`, `tl-2021`, `tl-today` | About — timeline chapters |
| `network`, `cta`, `contact`, `vision` | Network header, closing CTA band, contact header, vision panel |
